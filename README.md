# 🎬 PeakTube

PeakTube is a Telegram bot developed by **PeakTeam** for downloading content from YouTube and Instagram.

The project is currently under active development and is not publicly launched yet.

## 🚧 Status

**In Development**

## ✨ About

PeakTube is being built with a focus on:

- Simple and user-friendly experience
- YouTube content downloading
- Instagram content downloading
- Automated processing
- Additional features currently under development
